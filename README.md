# Mac YOLO Safeguards downloads

Signed and notarized builds of [Mac YOLO Safeguards](https://macyolosafeguards.io), a macOS menu bar app that keeps AI coding agents from overloading your Mac.

Download the latest version from [macyolosafeguards.io](https://macyolosafeguards.io) or the [Releases](https://github.com/IgorGanapolsky/mac-yolo-safeguards-releases/releases) page. Check a download with `shasum -a 256 -c SHA256SUMS`.

Questions or bugs: open an issue here.
